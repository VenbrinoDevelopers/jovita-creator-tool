# @jovita-ai/sdk

The public TypeScript SDK for declaring Jovita apps, tools, and broker operations. Provider credentials stay in the broker database; Jovita Cloud keeps its broker endpoint private.

Install with `npm install @jovita-ai/sdk zod`. Use `@jovita-ai/cli` to build and submit the app.

See the [creator tool guide](https://github.com/VenbrinoDevelopers/jovita-creator-tool#readme).
